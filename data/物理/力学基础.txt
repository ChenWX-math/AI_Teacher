# 力学基础

## 一、运动学

### 1. 匀变速直线运动
五大基本公式：
- v = v₀ + at
- x = v₀t + ½at²
- v² - v₀² = 2ax
- x = (v₀ + v)t / 2
- Δx = aT²（连续相等时间内的位移差为定值）

### 2. 自由落体与竖直上抛
- 自由落体：v₀ = 0，a = g ≈ 10 m/s²
- 竖直上抛：上升和下降为对称过程，最高点 v = 0

### 3. 运动图像
- v-t 图：斜率 = 加速度，面积 = 位移
- x-t 图：斜率 = 速度，切线方向 = 速度方向

## 二、相互作用与受力分析

### 1. 三大性质力
- 重力 G = mg，方向竖直向下，作用点在重心
- 弹力 F = kx（胡克定律），方向垂直于接触面
- 摩擦力：静摩擦力随外力变化（0 < f ≤ μₛN），滑动摩擦力 f = μN

### 2. 受力分析步骤
① 确定研究对象（整体法/隔离法）
② 按重力→弹力→摩擦力→其他力的顺序分析
③ 画受力分析图
④ 建立坐标系，正交分解

### 3. 共点力平衡
- 二力平衡：等大反向同一直线
- 三力平衡：任意两力合力与第三力等大反向（或三角形法则）
- 多力平衡：正交分解，∑Fx = 0，∑Fy = 0

## 三、牛顿运动定律

### 1. 牛顿三定律
- 第一定律（惯性定律）：物体在不受外力时保持静止或匀速直线运动
- 第二定律：F = ma（力是改变运动状态的原因，不是维持运动的原因）
- 第三定律：作用力与反作用力等大反向，作用在不同物体上

### 2. 两类动力学问题
已知力求运动 → F→a→v/x/t
已知运动求力 → v/x/t→a→F

### 3. 超重与失重
- 超重：a 向上，N > mg（加速上升或减速下降）
- 失重：a 向下，N < mg（加速下降或减速上升）
- 完全失重：a = g，N = 0

## 四、曲线运动

### 1. 运动的合成与分解
- 合运动 = 各分运动的矢量叠加
- 等时性：各分运动时间相同
- 独立性：各分运动互不干扰

### 2. 平抛运动
- 水平：匀速直线 x = v₀t
- 竖直：自由落体 y = ½gt²
- 合速度：v = √(v₀² + (gt)²)，方向 tan θ = gt/v₀

### 3. 圆周运动
- 线速度 v = 2πr/T，角速度 ω = 2π/T
- 向心加速度 a = v²/r = ω²r
- 向心力 F = mv²/r = mω²r（效果力，不是独立性质的力）
- 绳模型（最高点 v_min = √(gr)）vs 杆模型（最高点 v_min = 0）

## 五、功与能

### 1. 功与功率
- W = F·s·cos θ（θ 为力与位移夹角）
- P = W/t = F·v（平均功率/瞬时功率）

### 2. 动能定理（核心！）
W_合 = ΔEk = ½mv₂² - ½mv₁²
适用范围极广，能解决牛顿定律解不了的问题

### 3. 机械能守恒（条件：只有重力或弹力做功）
mgh₁ + ½mv₁² = mgh₂ + ½mv₂²

## 六、易错点
- 速度为零时加速度不一定为零（如竖直上抛最高点）
- 摩擦力方向不一定与运动方向相反（如传送带）
- 超重失重不是重力变了，是支持力变了
- 向心力是效果力，不是单独的力
- 机械能守恒的条件是"只有重力/弹力做功"，不是"只受重力/弹力"
