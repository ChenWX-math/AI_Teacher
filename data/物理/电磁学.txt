# 电磁学

## 一、静电场

### 1. 库仑定律
F = k·Q₁Q₂ / r²（真空中，k = 9×10⁹ N·m²/C²）

### 2. 电场强度
E = F/q（定义式），E = kQ/r²（点电荷），E = U/d（匀强电场）
方向：正电荷受力方向

### 3. 电场线与等势面
- 电场线从正电荷出发，终止于负电荷
- 等势面与电场线垂直
- 沿电场线方向电势降低

### 4. 电势能与电势
- W_AB = qU_AB = q(φA - φB)
- 电势能 Ep = qφ
- 电势差 U = Ed（匀强电场）

### 5. 电容器
C = Q/U = εS/(4πkd)
动态分析口诀：Q 不变时 E 不变断开电源，U 不变时 d 增 C 减 Q 减

## 二、恒定电流

### 1. 欧姆定律
部分电路：I = U/R
闭合电路：I = E/(R + r)

### 2. 电阻定律
R = ρL / S

### 3. 电功与电热
- 纯电阻：W = Q = UIt = I²Rt = U²t/R
- 非纯电阻（电动机）：W = UIt（总功）> Q = I²Rt（发热）

### 4. 闭合电路动态分析
"串反并同"——某电阻增大时，与之串联的用电器电压/电流减小，与之并联的增大

## 三、磁场

### 1. 安培力（通电导线在磁场中受力）
F = BIL·sin θ（θ 为 B 与 I 的夹角）
方向：左手定则（B 穿手心，四指指向 I，拇指指向 F）

### 2. 洛伦兹力（运动电荷在磁场中受力）
F = qvB·sin θ
特点：不做功（始终垂直于速度方向）

### 3. 带电粒子在匀强磁场中的运动
- v ∥ B：匀速直线
- v ⊥ B：匀速圆周，半径 r = mv/(qB)，周期 T = 2πm/(qB)
- 周期与速度无关！这是回旋加速器的原理

## 四、电磁感应

### 1. 产生感应电流的条件
穿过闭合回路的磁通量发生变化

### 2. 楞次定律（判断感应电流方向）
感应电流的磁场总是阻碍引起感应电流的磁通量变化。
口诀：增反减同、来拒去留

### 3. 法拉第电磁感应定律
E = n·ΔΦ/Δt
- 导线切割磁感线：E = BLv（B⊥L⊥v）
- 旋转切割：E = ½BL²ω

### 4. 右手定则（判断感应电流方向）
适用于导体切割磁感线：B 穿手心，拇指指向运动方向，四指指向感应电流方向

## 五、交变电流

### 1. 正弦交变电
最大值 Em = nBSω
有效值 E = Em/√2（正弦交流电）

### 2. 变压器
U₁/U₂ = n₁/n₂，I₁/I₂ = n₂/n₁（理想变压器）
副线圈决定原线圈的输入与输出

### 3. 远距离输电
采用高压输电（减小电流→减小线路损耗 P = I²R）

## 六、易错点
- 安培力左手 vs 洛伦兹力左手（都是左手定则！）
- 楞次定律的"阻碍"不是"阻止"，是"延缓"
- 洛伦兹力不做功（改变速度方向但不改变大小）
- 带电粒子在复合场中运动的受力分析
- 变压器输入电压决定输出电压，输出功率决定输入功率
