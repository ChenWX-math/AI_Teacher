# 元素化合物

## 一、金属元素

### 1. 钠（Na）
- 银白色、质软、密度比水小（浮在水面）
- 与 O₂：常温生成 Na₂O（白色），加热生成 Na₂O₂（淡黄色）
- 与水：2Na + 2H₂O = 2NaOH + H₂↑（浮熔游响红）
- Na₂O₂ 与水/CO₂：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑（漂白剂/供氧剂）

### 2. 铝（Al）
- 两性金属：既能与酸反应，也能与强碱反应
- 2Al + 6H⁺ = 2Al³⁺ + 3H₂↑
- 2Al + 2OH⁻ + 2H₂O = 2AlO₂⁻ + 3H₂↑
- Al₂O₃、Al(OH)₃ 均为两性化合物，但不与弱酸/弱碱反应
- 铝热反应：2Al + Fe₂O₃→2Fe + Al₂O₃（高温）

### 3. 铁（Fe）
- Fe 与弱氧化剂（H⁺、S、I₂、Cu²⁺）→ Fe²⁺
- Fe 与强氧化剂（Cl₂、Br₂、浓HNO₃/浓H₂SO₄加热）→ Fe³⁺
- Fe²⁺检验：加 KSCN 无现象，再加氯水→溶液变红
- Fe³⁺检验：加 KSCN→溶液变红（血红色 Fe(SCN)₃）

## 二、非金属元素

### 1. 氯（Cl₂）
- 黄绿色、有刺激性气味、有毒
- 与水：Cl₂ + H₂O ⇌ HCl + HClO（HClO 有漂白性，是漂白液的有效成分）
- 与碱：Cl₂ + 2NaOH = NaCl + NaClO + H₂O
- 实验室制 Cl₂：MnO₂ + 4HCl(浓) → MnCl₂ + Cl₂↑ + 2H₂O（需加热）

### 2. 硫（S）
- SO₂ 有漂白性（化合型，加热颜色恢复，区别于 Cl₂ 的氧化型漂白）
- 浓 H₂SO₄ 特性：吸水性（干燥剂）、脱水性（碳化）、强氧化性
- 浓 H₂SO₄ 与 Cu（需加热）：Cu + 2H₂SO₄(浓) = CuSO₄ + SO₂↑ + 2H₂O

### 3. 氮（N₂）
- NH₃ 实验室制法：2NH₄Cl + Ca(OH)₂ = CaCl₂ + 2NH₃↑ + 2H₂O
- NH₃ 检验：湿润红色石蕊试纸变蓝 / 蘸浓盐酸靠近有白烟
- HNO₃ 特性：与金属反应不生成 H₂（因强氧化性，生成 NO/NO₂）
- 浓 HNO₃ 与 Fe/Al 常温钝化

### 4. 硅（Si）
- SiO₂ 是酸性氧化物（与 HF 反应，与碱反应）
- 半导体材料，太阳能电池
- HF 腐蚀玻璃：SiO₂ + 4HF = SiF₄↑ + 2H₂O

## 三、必会转化关系图（铁三角）
```
       Fe
      /  \
  Fe²⁺ ←→ Fe³⁺
```
- Fe → Fe²⁺：与酸/弱氧化剂
- Fe → Fe³⁺：与强氧化剂
- Fe²⁺ → Fe³⁺：与氧化剂（Cl₂/H₂O₂/HNO₃）
- Fe³⁺ → Fe²⁺：与还原剂（Fe/Zn/Cu/Vc）

## 四、易错点
- SO₂ 使品红褪色是化合反应（可逆），Cl₂ 是氧化反应（不可逆）
- 浓 H₂SO₄ 参与的反应很多需要加热
- 浓 HNO₃ 与金属反应不放 H₂
- Fe 与 HNO₃ 过量不足，产物不同
