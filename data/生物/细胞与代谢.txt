# 细胞的结构与代谢

## 一、细胞的结构

### 1. 细胞膜
- 成分：磷脂双分子层 + 蛋白质 + 糖类
- 结构特点：流动性（磷脂和蛋白质可运动）
- 功能特点：选择透过性
- 物质跨膜运输：
  - 自由扩散：顺浓度，不需载体，不需能量（O₂、CO₂、甘油）
  - 协助扩散：顺浓度，需载体/通道蛋白，不需能量（葡萄糖进入红细胞）
  - 主动运输：逆浓度，需载体，需能量（离子、氨基酸、葡萄糖进入小肠上皮）

### 2. 细胞器（重点）
- 线粒体：双层膜，有氧呼吸主要场所，含少量 DNA（母系遗传）
- 叶绿体：双层膜，光合作用场所，含少量 DNA
- 内质网：蛋白质加工和脂质合成（粗面有核糖体，滑面无）
- 高尔基体：对蛋白质进一步加工、分类、包装；植物细胞中与细胞壁形成有关
- 核糖体：蛋白质合成场所，无膜结构
- 溶酶体：含多种水解酶，分解衰老细胞器和外来物质

## 二、酶与 ATP

### 1. 酶
- 本质：大多数是蛋白质（少数 RNA 也有催化作用）
- 特性：高效性、专一性、作用条件温和（需适宜温度和 pH）
- 酶活性受温度/pH 影响（低温抑制但可恢复，高温/过酸过碱使酶失活→不可恢复）
- 抑制剂：竞争性（与底物结构相似）和非竞争性（改变酶空间结构）

### 2. ATP（细胞的能量货币）
- 结构简式：A—P～P～P（高能磷酸键用～表示）
- ATP ⇌ ADP + Pi + 能量（ATP 水解酶/ATP 合成酶）
- 产生途径：细胞呼吸（动物+植物）、光合作用（植物光反应阶段）

## 三、光合作用

### 1. 光合色素
- 叶绿素 a（蓝绿色）、叶绿素 b（黄绿色）
- 类胡萝卜素：胡萝卜素（橙黄色）、叶黄素（黄色）
- 吸收光谱：红光和蓝紫光（绿光几乎不吸收→叶子呈绿色）

### 2. 光反应（类囊体薄膜上）
- 条件：光、色素、酶、水
- 物质变化：水光解 H₂O → [H] + O₂ / ADP+Pi → ATP
- 能量变化：光能 → ATP 中的活跃化学能

### 3. 暗反应（叶绿体基质中）
- 条件：酶、[H]、ATP、CO₂
- CO₂ 固定：CO₂ + C₅ → 2C₃
- C₃ 还原：2C₃ → (CH₂O) + C₅（消耗[H]+ATP）
- 能量变化：ATP 中的活跃化学能 → 有机物中的稳定化学能

### 4. 影响光合作用的因素
- 光照强度（CO₂ 吸收速率随光照先增后稳）、CO₂ 浓度、温度、水、矿质元素

## 四、细胞呼吸

### 1. 有氧呼吸（三步）
- 第一阶段（细胞质基质）：葡萄糖 → 2 丙酮酸 + 少量[H] + 少量 ATP
- 第二阶段（线粒体基质）：丙酮酸 + H₂O → CO₂ + 大量[H] + 少量 ATP
- 第三阶段（线粒体内膜）：[H] + O₂ → H₂O + 大量 ATP
- 总反应式：C₆H₁₂O₆ + 6O₂ + 6H₂O → 6CO₂ + 12H₂O + 能量（38ATP）

### 2. 无氧呼吸
- 动物/乳酸菌：葡萄糖 → 乳酸 + 少量能量
- 酵母菌/大多数植物：葡萄糖 → 酒精 + CO₂ + 少量能量

## 五、易错点
- 暗反应不需要光，但需要光反应提供 [H] 和 ATP
- 有氧呼吸三个阶段都有 ATP 产生（第三阶段最多）
- 线粒体和叶绿体都是双层膜结构
- 光合作用释放的 O₂ 来自 H₂O 的光解，不是 CO₂
