# 三角函数与解三角形

## 一、任意角与弧度制

### 1. 任意角
- 正角：逆时针旋转；负角：顺时针旋转
- 终边相同的角：α + 2kπ（k ∈ Z）
- 象限角：根据终边所在象限命名

### 2. 弧度制
- 定义：弧长等于半径的弧所对的圆心角为 1 弧度
- 换算：180° = π 弧度，1° = π/180 弧度
- 弧长公式：l = |α|·r
- 扇形面积：S = (1/2)×l×r = (1/2)×|α|×r²

## 二、任意角的三角函数

### 1. 定义（单位圆法）
在平面直角坐标系中，设角 α 的终边上一点 P(x, y)，|OP| = r，则：
- sin α = y / r
- cos α = x / r
- tan α = y / x（x ≠ 0）

### 2. 各象限三角函数值的符号
- 一全正，二正弦，三正切，四余弦
- 口诀记忆：一全正、二正弦、三双切、四余弦

### 3. 诱导公式（奇变偶不变，符号看象限）
- sin(-α) = -sin α，cos(-α) = cos α，tan(-α) = -tan α
- sin(π - α) = sin α，cos(π - α) = -cos α
- sin(π + α) = -sin α，cos(π + α) = -cos α
- sin(π/2 - α) = cos α，cos(π/2 - α) = sin α

### 4. 同角三角函数基本关系
- 平方关系：sin²α + cos²α = 1
- 商数关系：tan α = sin α / cos α
- 此外还有：1 + tan²α = sec²α，1 + cot²α = csc²α

## 三、三角函数的图像与性质

### 1. y = sin x
- 定义域：R；值域：[-1, 1]
- 周期：2π；奇函数，关于原点对称
- 增区间：[2kπ - π/2, 2kπ + π/2]
- 减区间：[2kπ + π/2, 2kπ + 3π/2]

### 2. y = cos x
- 定义域：R；值域：[-1, 1]
- 周期：2π；偶函数，关于 y 轴对称
- 增区间：[2kπ - π, 2kπ]
- 减区间：[2kπ, 2kπ + π]

### 3. y = tan x
- 定义域：{x | x ≠ kπ + π/2, k ∈ Z}
- 值域：R；周期：π；奇函数

### 4. y = A·sin(ωx + φ) 型函数
- 振幅：|A|；周期：T = 2π/|ω|
- 频率：f = 1/T = |ω|/(2π)
- 相位：ωx + φ；初相：φ
- 图像变换：「左加右减平移，横向伸缩改变 ω，纵向伸缩改变 A」

## 四、三角恒等变换

### 1. 和差公式
- sin(α ± β) = sin α·cos β ± cos α·sin β
- cos(α ± β) = cos α·cos β ∓ sin α·sin β
- tan(α ± β) = (tan α ± tan β) / (1 ∓ tan α·tan β)

### 2. 倍角公式
- sin 2α = 2·sin α·cos α
- cos 2α = cos²α - sin²α = 2cos²α - 1 = 1 - 2sin²α
- tan 2α = 2tan α / (1 - tan²α)

### 3. 降幂公式
- sin²α = (1 - cos 2α) / 2
- cos²α = (1 + cos 2α) / 2

### 4. 辅助角公式
a·sin x + b·cos x = √(a²+b²)·sin(x + φ)，其中 tan φ = b/a（a ≠ 0）

## 五、解三角形

### 1. 正弦定理
a / sin A = b / sin B = c / sin C = 2R（R 为外接圆半径）

使用场景：已知两角一边，或两边一对角

### 2. 余弦定理
- a² = b² + c² - 2bc·cos A
- b² = a² + c² - 2ac·cos B
- c² = a² + b² - 2ab·cos C

使用场景：已知两边一夹角，或已知三边

### 3. 面积公式
- S = (1/2)·a·b·sin C = (1/2)·b·c·sin A = (1/2)·a·c·sin B
- 海伦公式：S = √[p(p-a)(p-b)(p-c)]，其中 p = (a+b+c)/2

### 4. 常见判定方法
- 已知两边一对角时，需讨论解的个数（无解/一解/两解）
- 大边对大角，大角对大边

### 5. 易错点
- 正弦定理中边角互化时的 2R 不可遗漏
- 三角形内角和为 π（不是 180°，看题目要求）
- 钝角三角形的余弦值为负
- 诱导公式搞混符号
