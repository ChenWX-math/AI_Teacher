# 导数及其应用

## 一、导数的概念

### 1. 平均变化率
函数 f(x) 从 x₁ 到 x₂ 的平均变化率：
[f(x₂) - f(x₁)] / (x₂ - x₁)

### 2. 瞬时变化率（导数定义）
f'(x₀) = lim[Δx→0] [f(x₀ + Δx) - f(x₀)] / Δx

导数的几何意义：曲线 y = f(x) 在点 (x₀, f(x₀)) 处切线的斜率。

### 3. 导函数
f'(x) 是函数 f(x) 的导函数（简称导数），表示 f(x) 在每一点的瞬时变化率。

## 二、常见函数的导数公式（必背！）

### 基本初等函数求导
- C' = 0（常数的导数为 0）
- (xⁿ)' = n·xⁿ⁻¹
- (sin x)' = cos x
- (cos x)' = -sin x
- (tan x)' = sec²x = 1/cos²x
- (eˣ)' = eˣ
- (aˣ)' = aˣ·ln a
- (ln x)' = 1/x
- (logₐ x)' = 1/(x·ln a)

## 三、求导法则

### 1. 四则运算
- [f(x) ± g(x)]' = f'(x) ± g'(x)
- [f(x)·g(x)]' = f'(x)·g(x) + f(x)·g'(x)
- [f(x)/g(x)]' = [f'(x)·g(x) - f(x)·g'(x)] / [g(x)]²  （g(x) ≠ 0）

### 2. 复合函数求导（链式法则，重中之重！）
若 y = f(g(x))，则 y' = f'(g(x)) · g'(x)

简记：dy/dx = (dy/du) × (du/dx)

示例：y = sin(2x + 1)
令 u = 2x + 1，则 y = sin u
y' = cos u × u' = cos(2x + 1) × 2 = 2·cos(2x + 1)

## 四、导数的应用

### 1. 求切线方程
曲线 y = f(x) 在 x = x₀ 处的切线方程：
y - f(x₀) = f'(x₀)(x - x₀)

### 2. 判断单调性
- f'(x) > 0 → f(x) 在该区间上单调递增
- f'(x) < 0 → f(x) 在该区间上单调递减
- f'(x) = 0 → 可能的极值点（需进一步验证）

解题步骤（四步法）：
① 求定义域
② 求导函数 f'(x)
③ 解方程 f'(x) = 0，找到驻点
④ 列表判断各区间符号，得出单调区间

### 3. 求极值和最值
极值判定（两种方法）：
- 第一充分条件：f'(x) 左正右负 → 极大值；左负右正 → 极小值
- 第二充分条件：f'(x₀) = 0 且 f''(x₀) < 0 → 极大值；f''(x₀) > 0 → 极小值

闭区间 [a, b] 上求最值：比较所有极值点和区间端点，取最大/最小值。

### 4. 恒成立问题（高频考点）
- f(x) ≥ m 恒成立 → f(x)的最小值 ≥ m
- f(x) ≤ m 恒成立 → f(x)的最大值 ≤ m
- 策略：求导 → 找最值 → 建立不等式 → 解参数范围

### 5. 不等式的证明
- 构造函数法：要证 g(x) ≥ h(x)，构造 F(x) = g(x) - h(x)
- 证明 F(x)的最小值 ≥ 0

## 五、易错点汇总
- 复合函数求导忘记乘内层导数（漏链）
- 混淆 f'(x₀)（一个数）和 f'(x)（一个函数）
- 求极值时忽略定义域限制
- ln x 的定义域是 x > 0，写单调区间时不能包含负数
- 分式求导套错公式、符号搞反
- 恒成立问题中"≥"和">"的细微差别
