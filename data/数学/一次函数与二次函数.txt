# 一次函数与二次函数

## 一、一次函数

### 1. 定义
形如 y = kx + b（k ≠ 0）的函数称为一次函数。其中 k 为斜率，b 为 y 轴截距。

### 2. 图像与性质
- 图像是一条直线
- k > 0 时，直线从左下到右上（y 随 x 增大而增大）
- k < 0 时，直线从左上到右下（y 随 x 增大而减小）
- b > 0 时，直线与 y 轴交于正半轴
- b < 0 时，直线与 y 轴交于负半轴
- b = 0 时，为正比例函数 y = kx，过原点

### 3. 必记公式
- 斜率公式：k = (y₂ - y₁) / (x₂ - x₁)
- 两点式：(y - y₁) / (y₂ - y₁) = (x - x₁) / (x₂ - x₁)
- 点斜式：y - y₀ = k(x - x₀)
- 截距式：x/a + y/b = 1

### 4. 常见题型
- 已知两点求一次函数解析式
- 判断函数增减性
- 求直线与坐标轴围成的三角形面积：S = |b²| / |2k|（k ≠ 0）
- 两直线位置关系：平行（k₁ = k₂, b₁ ≠ b₂）、重合、相交

### 5. 易错点
- 忽略 k ≠ 0 的条件
- 将截距与距离混淆（截距可正可负，距离非负）
- 斜率不存在的情况（垂直于 x 轴的直线 x = c 不是一次函数）


## 二、二次函数

### 1. 定义与三种形式
形如 y = ax² + bx + c（a ≠ 0）的函数称为二次函数。

- 一般式：y = ax² + bx + c
- 顶点式：y = a(x - h)² + k，顶点为 (h, k)
- 交点式：y = a(x - x₁)(x - x₂)，其中 x₁、x₂ 为与 x 轴交点的横坐标

### 2. 图像（抛物线）
- a > 0 时，开口向上，有最小值
- a < 0 时，开口向下，有最大值
- |a| 越大，开口越窄
- 对称轴：x = -b / (2a)
- 顶点坐标：(-b/(2a), (4ac-b²)/(4a))

### 3. 判别式与根的分布
- Δ = b² - 4ac
- Δ > 0：与 x 轴有两个交点（两个不等实根）
- Δ = 0：与 x 轴相切（一个重根）
- Δ < 0：与 x 轴无交点（无实根）
- 韦达定理：x₁ + x₂ = -b/a，x₁·x₂ = c/a

### 4. 最值问题
- 在对称轴处取得最值
- 给定区间上的最值需比较端点和顶点
- 实际应用：最大利润、最小成本、最优方案

### 5. 常见题型
- 求顶点坐标、对称轴、与坐标轴交点
- 图像平移：「左加右减，上加下减」
- 根据条件求解析式（三点法、顶点法、交点法）
- 二次函数与方程、不等式的联系
- 实际应用题（最大面积、最值问题）

### 6. 易错点
- 忽略 a ≠ 0 的条件
- 顶点坐标的符号搞反
- 区间最值只算顶点不比较端点
- 图像平移口诀用反
