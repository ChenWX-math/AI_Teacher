# 数列

## 一、数列的基本概念

### 1. 定义
按照一定顺序排列的一列数称为数列，记作 {aₙ}。其中 a₁ 称为首项，aₙ 称为通项。

### 2. 通项公式
表示数列第 n 项与序号 n 的关系式，如 aₙ = 2n + 1。

### 3. 递推公式
表示相邻几项关系的式子，如 aₙ₊₁ = aₙ + d。

### 4. 前 n 项和 Sₙ
Sₙ = a₁ + a₂ + ... + aₙ

Sₙ 与 aₙ 的关系（重要！）：
- 当 n = 1 时，a₁ = S₁
- 当 n ≥ 2 时，aₙ = Sₙ - Sₙ₋₁

## 二、等差数列

### 1. 定义与通项
- 定义：从第二项起，每一项与前一项的差为常数 d（公差）
- 递推：aₙ₊₁ = aₙ + d
- 通项公式：aₙ = a₁ + (n - 1)d

### 2. 前 n 项和公式
- Sₙ = n(a₁ + aₙ) / 2
- Sₙ = na₁ + n(n - 1)d / 2

### 3. 等差中项
若 a、A、b 成等差数列，则 A = (a + b) / 2

### 4. 重要性质
- 若 m + n = p + q，则 aₘ + aₙ = aₚ + aₚ
- 等间隔取出的项仍成等差数列
- Sₙ, S₂ₙ - Sₙ, S₃ₙ - S₂ₙ 也成等差数列

### 5. 判定方法
- aₙ₊₁ - aₙ = 常数
- aₙ = pn + q（一次函数形式）
- Sₙ = An² + Bn（不含常数项的二次函数形式）

## 三、等比数列

### 1. 定义与通项
- 定义：从第二项起，每一项与前一项的比为常数 q（公比，q ≠ 0）
- 递推：aₙ₊₁ = aₙ · q
- 通项公式：aₙ = a₁ · qⁿ⁻¹

### 2. 前 n 项和公式
- 当 q = 1 时，Sₙ = na₁
- 当 q ≠ 1 时，Sₙ = a₁(1 - qⁿ) / (1 - q)

### 3. 等比中项
若 a、G、b 成等比数列，则 G² = a·b（G = ±√(ab)）

### 4. 重要性质
- 若 m + n = p + q，则 aₘ · aₙ = aₚ · aₚ
- 等间隔取出的项仍成等比数列
- Sₙ, S₂ₙ - Sₙ, S₃ₙ - S₂ₙ 也成等比数列（q ≠ -1 时）

### 5. 判定方法
- aₙ₊₁ / aₙ = 常数（q ≠ 0）
- aₙ = c·qⁿ（指数函数形式）
- aₙ₊₁² = aₙ · aₙ₊₂

## 四、常见数列求和技巧

### 1. 分组求和
把数列拆成几个等差/等比数列分别求和再相加。

### 2. 裂项相消（重点！）
- 1 / [n(n+1)] = 1/n - 1/(n+1)
- 1 / [n(n+k)] = (1/k)·[1/n - 1/(n+k)]
- 1 / [(2n-1)(2n+1)] = (1/2)·[1/(2n-1) - 1/(2n+1)]

### 3. 错位相减（等差×等比求和必用）
用于求 cₙ = aₙ·bₙ 的前 n 项和，其中 {aₙ} 是等差数列，{bₙ} 是等比数列。
步骤：写出 Sₙ → 乘以公比 q → 两式相减 → 等比求和

### 4. 倒序相加
当 a₁ + aₙ = a₂ + aₙ₋₁ = ... 时使用。

## 五、数列综合与易错点

### 1. 通项与递推互求
- 已知 Sₙ 求 aₙ：分段讨论 n = 1 和 n ≥ 2
- 累加法：aₙ₊₁ - aₙ = f(n) 型
- 累乘法：aₙ₊₁ / aₙ = g(n) 型
- 构造法：aₙ₊₁ = p·aₙ + q 型，两边配凑转化为等比数列

### 2. 易错点
- 已知 Sₙ 求 aₙ 时忘记验证 n = 1 是否满足通项
- 等比数列求和时忘记 q = 1 的特殊情况
- 等比数列各项均不为 0
- 裂项时系数搞错，忘了加上 1/k
