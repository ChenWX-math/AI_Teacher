# 解析几何

## 一、直线方程

### 1. 五种形式
- 一般式：Ax + By + C = 0（A、B 不同时为 0）
- 点斜式：y - y₀ = k(x - x₀)
- 斜截式：y = kx + b
- 两点式：(y - y₁)/(y₂ - y₁) = (x - x₁)/(x₂ - x₁)
- 截距式：x/a + y/b = 1（ab ≠ 0）

### 2. 两直线的位置关系
- 平行：k₁ = k₂ 且 b₁ ≠ b₂
- 垂直：k₁ · k₂ = -1
- 重合：k₁ = k₂ 且 b₁ = b₂
- 夹角公式：tan θ = |k₂ - k₁| / |1 + k₁ k₂|（k₁ k₂ ≠ -1）

### 3. 距离公式
- 两点距离：d = √[(x₁-x₂)² + (y₁-y₂)²]
- 点到直线距离：d = |Ax₀ + By₀ + C| / √(A² + B²)
- 平行线距离：d = |C₁ - C₂| / √(A² + B²)

## 二、圆的方程

### 1. 两种形式
- 标准方程：(x - a)² + (y - b)² = r²，圆心 (a, b)，半径 r
- 一般方程：x² + y² + Dx + Ey + F = 0（D² + E² - 4F > 0）
  - 圆心：(-D/2, -E/2)
  - 半径：r = √(D² + E² - 4F) / 2

### 2. 直线与圆的位置关系
圆心到直线的距离 d 与半径 r 比较：
- d < r → 相交（两个交点，弦长 = 2√(r²-d²)）
- d = r → 相切（一个切点）
- d > r → 相离（无交点）

### 3. 圆与圆的位置关系
比较圆心距 d 与半径和 R+r、半径差 |R-r|：
- d > R + r → 外离
- d = R + r → 外切
- |R - r| < d < R + r → 相交
- d = |R - r| → 内切
- d < |R - r| → 内含

### 4. 切线方程
过圆 (x - a)² + (y - b)² = r² 上一点 P(x₀, y₀) 的切线：
(x₀ - a)(x - a) + (y₀ - b)(y - b) = r²

## 三、椭圆

### 1. 定义
平面内到两个定点 F₁、F₂ 的距离之和为常数 2a 的点的轨迹（2a > |F₁F₂|）。

### 2. 标准方程和性质
焦点在 x 轴：x²/a² + y²/b² = 1（a > b > 0）

- a：长半轴；b：短半轴；c：半焦距
- 关系：a² = b² + c²
- 离心率：e = c/a（0 < e < 1，e 越接近 0 越圆，越接近 1 越扁）
- 焦点：F₁(-c, 0), F₂(c, 0)
- 准线：x = ±a²/c

### 3. 焦点三角形
- 周长：2a + 2c
- 面积：b²·tan(θ/2)，其中 θ = ∠F₁PF₂

### 4. 椭圆的光学性质
从椭圆一个焦点发出的光线，经椭圆反射后必经过另一个焦点。

## 四、双曲线

### 1. 定义
平面内到两个定点 F₁、F₂ 的距离之差的绝对值为常数 2a 的点的轨迹（0 < 2a < |F₁F₂|）。

### 2. 标准方程和性质
焦点在 x 轴：x²/a² - y²/b² = 1（a > 0, b > 0）

- a：实半轴；b：虚半轴；c：半焦距
- 关系：c² = a² + b²
- 离心率：e = c/a（e > 1）
- 焦点：F₁(-c, 0), F₂(c, 0)
- 渐近线：y = ±(b/a)·x

### 3. 等轴双曲线
a = b 时，离心率 e = √2，渐近线 y = ±x

### 4. 共轭双曲线
x²/a² - y²/b² = 1 与 y²/b² - x²/a² = 1 互为共轭双曲线，有共同的渐近线。

## 五、抛物线

### 1. 定义
平面内到定点 F（焦点）与到定直线 l（准线）距离相等的点的轨迹。

### 2. 四种标准方程（必背）
| 开口方向 | 标准方程   | 焦点        | 准线      |
|---------|-----------|------------|----------|
| 右      | y² = 2px  | (p/2, 0)   | x = -p/2 |
| 左      | y² = -2px | (-p/2, 0)  | x = p/2  |
| 上      | x² = 2py  | (0, p/2)   | y = -p/2 |
| 下      | x² = -2py | (0, -p/2)  | y = p/2  |

### 3. 抛物线的几何性质
- p 的几何意义：焦点到准线的距离
- 通径：过焦点且垂直于对称轴的弦，长为 2p
- 抛物线上一点到焦点距离 = 该点到准线距离

## 六、综合解题策略

### 1. 设而不求（解析几何核心思想）
设出交点坐标但不去具体求解，利用韦达定理整体处理。

### 2. 弦长公式
直线 y = kx + m 与曲线交于 A(x₁, y₁)、B(x₂, y₂)：
|AB| = √(1 + k²) · √[(x₁+x₂)² - 4x₁x₂]

### 3. 中点弦问题
已知弦中点 P(x₀, y₀)，求弦所在直线方程 → 点差法。

### 4. 定点定值问题
证明某几何量（如乘积、和、斜率积等）为定值，或某直线恒过定点。

### 5. 易错点
- 椭圆和双曲线中 a、b、c 的关系搞混（椭圆 a 最大，双曲线 c 最大）
- 忘记讨论斜率不存在的情况（垂直于 x 轴的直线）
- 抛物线四种标准方程记混（p > 0 还是 p < 0）
- 计算量大的时候容易出错，多用因式分解和整体代入简化
