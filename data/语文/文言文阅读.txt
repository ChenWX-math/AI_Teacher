# 文言文阅读

## 一、文言文基础

### 1. 常见实词（必背高频词）
- 之：代词（他/它/这）/ 助词（的）/ 动词（去、往）/ 取独（主谓间取消独立性）
- 而：表并列（又）/ 表递进（而且）/ 表承接（就）/ 表转折（却）/ 表修饰（地）
- 以：介词（用、把、凭、因为）/ 连词（来、用来）/ 动词（认为）
- 其：代词（他/它/那/其中的）/ 副词（大概、难道、还是）
- 乃：于是、才、竟然、是（判断句）
- 于：在、从、对、比（表比较）、被（表被动）

### 2. 常见虚词
- 者：……的人 / 表停顿 / 表判断
- 也：句末语气词（表判断/陈述/疑问/感叹）/ 句中停顿
- 焉：于之（兼词）/ 哪里（疑问代词）/ 句末语气词
- 何：什么/怎么/为什么/多么
- 为：做（动词）/ 被（介词，表被动）/ 因为（介词）/ 替（介词）/ 句末语气词

### 3. 通假字与古今异义
- 通假字：说→悦（高兴）、女→汝（你）、见→现（出现）、反→返（返回）
- 古今异义：妻子（古：妻子儿女 / 今：老婆）、交通（古：交错相通 / 今：运输）、牺牲（古：祭祀牲畜 / 今：为正义献身）

### 4. 词类活用
- 名词作动词：军霸上（驻军）、左右欲刃相如（杀）
- 形容词作动词：素善留侯张良（交好）
- 使动用法：项伯杀人，臣活之（使……活）
- 意动用法：孔子登东山而小鲁（认为……小）
- 名词作状语：天下云集响应（像云一样 / 像回声一样）

## 二、特殊句式

### 1. 判断句
标志：……者……也 / 乃 / 为 / 即 / 则 / 是
例句：师者，所以传道受业解惑也。

### 2. 被动句
标志：于 / 见 / 为 / 被 / 为……所
例句：吾长见笑于大方之家。

### 3. 倒装句
- 宾语前置：何陋之有？（正常语序：有何陋）
- 定语后置：马之千里者（正常语序：千里马）
- 状语后置：青，取之于蓝（正常语序：青，于蓝取之）
- 主谓倒装：甚矣，汝之不惠！（正常语序：汝之不惠甚矣）

### 4. 省略句
- 省主语：（烛之武）辞曰：臣之壮也，犹不如人
- 省宾语：竖子不足与（之）谋
- 省介词：晋军（于）函陵

## 三、翻译方法（六字诀）

| 方法 | 说明 | 示例 |
|------|------|------|
| 留 | 人名、地名、官名、年号不译 | 沛公→沛公 |
| 删 | 无实义的虚词删去 | 句首发语词"夫" |
| 换 | 古今异义词换成现代说法 | 吾→我，汝→你 |
| 补 | 补出省略成分 | （你）去 |
| 调 | 调整倒装语序 | 何陋之有→有何陋 |
| 贯 | 修辞、典故灵活意译 | 金城千里→坚固的城池 |

## 四、高频考点文言篇目

- 《劝学》（荀子）：学习的重要性、善假于物、积累与坚持
- 《师说》（韩愈）：从师学习的必要性、道之所存师之所存
- 《赤壁赋》（苏轼）：变与不变的哲理、主客问答
- 《陈情表》（李密）：孝道、真情实感
- 《烛之武退秦师》（《左传》）：外交辞令、利益分析

## 五、易错点
- "之"的 4 种用法混淆（代词/助词/动词/取独）
- 宾语前置的标志词漏看（之、是）
- 被动句与主动句混淆
- 翻译过于直译，不通顺
- 省略成分补充错误
